# Fontes

Catálogo das fontes da edição 0.1.0 e critérios de uso. Todas as fontes foram acessadas em 8 de outubro de 2026. O cadastro que alimenta o atlas está em `content/published/fontes.json`; este arquivo o apresenta para leitura e é gerado a partir dele.

## Critérios de uso

1. **A evidência vem do documento lido.** Cada documento foi baixado e lido. A busca na web serviu só para localizar endereços; nenhum resumo de busca foi usado como evidência.
2. **Ordem de preferência.** Primeiro o dado oficial estruturado (TSE, Senado, Câmara). Depois a nota ou notícia do próprio órgão que decidiu (STF, TSE, TRF4, Ministério Público). Depois as agências públicas de notícias (Agência Brasil, Agência Senado, Agência Câmara). Depois a biografia institucional. Por último, jornalismo com veículo e data.
3. **Jornalismo tem uso restrito.** Entra quando não foi localizado documento oficial para o fato, ou para registrar o desdobramento de um caso. O texto do acontecimento diz qual veículo informa o quê.
4. **Biografia institucional serve à cronologia, com ressalvas.** A biografia de Lula publicada pela Presidência cobre até 2006 e não traz dia e mês de vários fatos. Onde havia dado do TSE, a data veio dele. Onde não havia, o registro ficou com precisão de ano.
5. **Toda citação diz onde olhar e o que o trecho sustenta.** São os campos `localizacao` e `evidencia` de cada citação. Em arquivos de dados, a localização indica o arquivo e a linha ou o campo.
6. **Nenhuma fonte desta edição é PDF.** Quando houver, a citação deve trazer página ou seção.
7. **Fonte que se contradiz com outra não é descartada.** A divergência é registrada em [CONTENT-REVIEW.md](CONTENT-REVIEW.md), com a versão adotada e o motivo.

## Como os documentos foram lidos

- **Páginas e notícias:** baixadas por um script, com o texto extraído do HTML. A leitura foi feita sobre esse texto.
- **TSE, DivulgaCandContas:** as fichas foram lidas pelo serviço REST do próprio sistema (`divulgacandcontas.tse.jus.br/divulga/rest/v1`). O endereço cadastrado é o da ficha pública correspondente, que o serviço informa no campo `txLink`.
- **TSE, repositório de dados eleitorais:** arquivos `consulta_cand` de 1994, 1998 e 2002, lidos nos CSV `_BR` e `_RJ`. A data do documento é a data de geração registrada no arquivo.
- **Senado e Câmara, dados abertos:** respostas JSON das APIs.
- **Segunda passagem:** para cada citação foram anotados os trechos literais que a sustentam, e um verificador conferiu se cada trecho existe na cópia baixada do documento. Resultado: 166 citações, 382 trechos conferidos, nenhuma falha. A lista de trechos está em `docs/evidencias/provas-2026-10-08.json`.

As cópias baixadas não fazem parte do repositório. Para repetir a conferência é preciso baixar os documentos de novo. Transformar isso em comando ficou fora da fase 3 (DECISIONS.md, D-36): o pipeline de dados não baixa nada. O relatório `npm run data:report` informa quantas citações de registros publicados têm trecho registrado.
